# Changelog

## 0.0.1 — 2026-07-10

First public release of Tawreed.

- BOQ `.xlsx` parsing with adaptive headers and merged-cell support.
- Bounded, schema-validated AI classification with exact item coverage.
- Codex ChatGPT login integration and live account model discovery.
- Summary-only approval before workbook export.
- Professional package sheets and Master sheet with preserved formulas.
- Local run history and operating-system credential storage.
- Minimal accessible Workbench, Runs, Settings, and About surfaces.
- English/Arabic RTL and Light/Dark/System appearance support.
- Portable one-file builds for Windows, macOS, and Linux.
