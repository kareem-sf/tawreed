# Tawreed brand

**The mark** is ت (taa), the first letter of توريد, set in Thmanyah Serif Display Bold and outlined. The gold bowl
is the letter; its two diamond dots are the two packages. The rules for using it are in
[GUIDELINES.md](GUIDELINES.md).

Tawreed is part of the **QS Mind** house (estimate, tender, procure: Quanta, Quantix, Tawreed). Outside the product
it carries the endorsement "by QS Mind" (`logo/tawreed-lockup-endorsed-*.svg`). Founded and developed by
[Kareem Safwat](https://kareemsafwat.com).

These files are copies from the QS Mind brand kit, which holds the generators and the PNG exports. Change the kit
and copy again; don't edit them here. The SVG masters are pure paths: the Thmanyah licence allows the outlined
letter as a logo but forbids redistributing the font, so no font file belongs in this folder or anywhere in the
repository.

## Files

| Path | What it is |
| --- | --- |
| `logo/tawreed-mark-*.svg` | The mark alone: solid on dark or light, and one-colour white or black |
| `logo/tawreed-lockup-horizontal-*.svg` | Mark and wordmark side by side, the default lockup |
| `logo/tawreed-lockup-stacked-*.svg` | Mark over wordmark, for square spaces |
| `logo/tawreed-lockup-endorsed-*.svg` | The horizontal lockup with "by QS Mind", for use outside the product |
| `icons/app-icon.svg`, `icons/app-icon-1024.png` | The app icon master; `desktop/icons/` is generated from the PNG |
| `icons/favicon.svg`, `favicon.ico`, `favicon-16/32.png` | Browser tab icons; `ui/public/favicon.svg` is a copy |
| `icons/apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable*`, `site.webmanifest` | Web and home-screen icons |
| `icons/icon.ico`, `icons/icon.icns` | Windows and macOS icons as the kit builds them |
| `social/og-image-1200x630.png` | Link preview image |
| `tokens.css` | The colours and brand font as CSS custom properties |
| `founder/k-mark.svg`, `k-mark-1024.png` | Kareem Safwat's K, unchanged |
| `founder/signature-on-dark/light.*` | The K with "Founded & developed by Kareem Safwat", for About screens and READMEs |
