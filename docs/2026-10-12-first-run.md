# First run: AI setup

Branch: `agent/qsm-264-first-run`, based on remote main `5abb29c`.

When no AI model is selected, Home shows one primary action, **Connect AI**, which opens Settings. The note explains adding a connection, checking a model and selecting it. BOQ import remains available as the secondary action. The prompt waits for settings to load; failed settings and project requests have a visible explanation and retry.

The About logs change remains in QSM-10 behind its explicit brand-v2 merge gate. Remote main still contains the older About page. This branch changes no About code and does not merge or release anything.

## Repeatable QA

1. Use a fresh, disposable `TAWREED_HOME`; never remove an existing customer's data folder. Start Tawreed without saved AI keys or models.
2. On Home, confirm **Connect AI** is the primary action. Click it: Settings and the empty connection form must appear. This navigation must not call an AI service or create a project.
3. Return Home, switch to Arabic: check the Arabic setup note, right-to-left layout and setup action. Repeat at a narrow window width.
4. Configure a connection, check its model, select it for Tawreed, then return Home. The setup prompt must disappear; BOQ import remains available. Use a synthetic BOQ only.
5. Restart: chosen settings must survive. Repeat first run in a second disposable home.
6. When the service cannot answer, Home must explain the failure and offer **Try again**. Once it answers, retry must restore the setup prompt or normal Home as appropriate.

Linux evidence uses the running Vite interface and real local Python service with an empty home, viewed with headless Chromium. English at 1000×800, Arabic at 1000×800 and 390×844 were inspected, with navigation checks, no page errors and no horizontal overflow. This is not evidence of a native installer or clean Windows installation. QA must repeat steps 1–5 on installed Linux and Windows builds after integration. About logs require a separate check after their gate clears.
