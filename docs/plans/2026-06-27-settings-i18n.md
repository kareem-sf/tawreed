# Settings Page i18n Refactoring

## Problem
The Settings page still contains hard-coded English strings that prevent complete bilingual (English/Arabic) support and RTL layout switching.

## User Impact
- Arabic-speaking users see mixed English/Arabic UI in Settings
- Layout direction doesn't properly switch for RTL languages
- Inconsistent with other pages (Workspace, History, About) which are already i18n-complete

## Target Behavior
All user-visible strings in the Settings page should be routed through the `i18n.tr()` system, with complete Arabic translations provided.

## Files to Touch
- `gui/pages/settings_page.py` - replace hard-coded strings with `self._i18n.tr("key")`
- `core/i18n.py` - add missing translation keys for Settings page strings

## Risk Level
**Low risk** - This is a UI-only refactoring that doesn't change behavior, just routes existing strings through the translation system.

## Acceptance Criteria
1. All hard-coded English strings in Settings page are replaced with i18n.tr() calls
2. Complete Arabic translations are added to TRANSLATIONS dict
3. Language switcher immediately updates Settings page text
4. RTL layout works correctly when Arabic is selected
5. All existing tests still pass
6. No functional changes to settings behavior

## Test Plan
- Run `pytest -q` - all tests should pass
- Run `ruff check .` and `ruff format --check .` - no linting issues
- Manual verification: launch app, switch to Arabic, verify all Settings strings are translated

## Rollback Plan
If issues arise, revert the single commit - no database changes or complex state to roll back.

## Scope Control
This PR stays within Tawreed's BOQ-to-work-package mission because it improves UI accessibility for Arabic-speaking quantity surveyors, which is directly related to the core workflow.

## Implementation Steps
1. Add all missing translation keys to `core/i18n.py`
2. Replace hard-coded strings in `gui/pages/settings_page.py` with `self._i18n.tr("key")`
3. Test language switching and RTL layout
4. Run test suite and linters
5. Create focused PR for review
