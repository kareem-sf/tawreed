# Future

Tawreed 0.0.1 intentionally supports one BOQ-to-workbook workflow. Future work
must preserve the summary-only UI and approval boundary.

Possible later additions:

- User-defined work-package taxonomies.
- Local/offline model providers.
- Resumable processing for very large BOQs.
- Organization-specific workbook templates.
- Signed portable binaries and automatic update verification.
- Additional interface languages.

Not planned for the desktop workflow: embedded spreadsheet editing, BOQ row
tables, raw AI consoles, or autonomous file/system tools.
