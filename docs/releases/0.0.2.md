Tawreed now runs on Mac as well as Windows and Linux, and this version fixes several problems found since the
first release.

## Download

- **Windows 10 and 11 (64-bit):** [Tawreed_x64-setup.exe](https://github.com/qs-mind/tawreed/releases/latest/download/Tawreed_x64-setup.exe)
- **Mac with Apple silicon (M1 or newer):** [Tawreed_aarch64.dmg](https://github.com/qs-mind/tawreed/releases/latest/download/Tawreed_aarch64.dmg)
- **Mac with an Intel chip:** [Tawreed_x64.dmg](https://github.com/qs-mind/tawreed/releases/latest/download/Tawreed_x64.dmg)
  (macOS 13 or newer)
- **Linux (64-bit):** [Tawreed_amd64.AppImage](https://github.com/qs-mind/tawreed/releases/latest/download/Tawreed_amd64.AppImage)
  (make it executable, then open it)

`SHA256SUMS.txt` lists each file's checksum.

**If you have Tawreed 0.0.1, download and install this version by hand, once.** Tawreed's update signing key
was replaced, so 0.0.1 cannot update itself to 0.0.2. Your projects and settings stay as they are. From 0.0.2 on,
Tawreed offers each new version by itself; press **Update and restart**.

## New

- **Tawreed for Mac**, on Apple silicon and on Intel. The Mac app is not signed with an Apple developer
  certificate yet, so macOS asks you to confirm it the first time:
  1. Open the `.dmg` and drag **Tawreed** to **Applications**. Open it from Applications, not from the `.dmg`.
  2. macOS says it cannot verify Tawreed. Click **Done**, then open **System Settings**, **Privacy & Security**,
     scroll down to the message about Tawreed and click **Open Anyway**. Confirm with your password.
  3. If you do not see that button, run this once in Terminal, then open Tawreed again:
     `xattr -dr com.apple.quarantine /Applications/Tawreed.app`

  You only do this the first time. Before you do, you can compare the file's checksum with `SHA256SUMS.txt`
  (`shasum -a 256 Tawreed_aarch64.dmg`).

## Fixed

- Adding a file on Linux no longer fails with an error (422).
- Arabic text shows correctly.
- Publishing no longer fails when a BOQ contains hidden characters pasted from Word.
- Many smaller reliability and safety fixes.

## Windows

The Windows installer is not code-signed yet, so Windows may show "Windows protected your PC". Choose
**More info**, then **Run anyway**.
