## Windows

The Windows installer is not code-signed yet, so Windows may show "Windows protected your PC". Choose
**More info**, then **Run anyway**.

## Mac

The Mac app is not signed with an Apple developer certificate yet, so macOS asks you to confirm it the first time.
Open the `.dmg`, drag **Tawreed** to **Applications**, and open it from Applications. When macOS says it cannot
verify Tawreed, open **System Settings**, **Privacy & Security**, and click **Open Anyway**.
